Subagent exploration reports are written for me to consume. What reaches the user is my conclusion: the decisions, the corrections, the open questions.

**Why:** Relaying a subagent's 20-point checklist and quoted code blocks wastes Antonio's attention and buries the two or three things that actually needed his input. The verbosity is not mine or the agent's to spend — it's his to read.

**How to apply:** Read the report, keep the findings that change the plan, and state them in my own compressed words. Never paste an agent's enumerated list, file inventory or code quotes. If a finding contradicts something I said earlier, verify it myself before repeating it — agents are sometimes wrong. Pairs with [[dont-recite-code-back-to-its-author]] and [[prefer-concise-responses]].
